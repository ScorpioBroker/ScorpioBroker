This type represents the data needed to define a Relationship as mandated by clause 4.5.3. The supported JSON members shall follow the requirements provided in Table 5.2.6-1 below. The datatype definition defines all the required attributes for the normalized representation. In the concise representation, the Attribute type member can be omitted as type="Relationship" can be inferred from the presence of the object member.
