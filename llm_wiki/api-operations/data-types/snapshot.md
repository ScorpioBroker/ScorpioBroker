This type represents the data needed to create and manage a Snapshot.
The supported JSON members shall follow the requirements provided in Table 5.2.41-1.

0..1 Allows clients to specify a list of queries whose results are to be part of the Snapshot. This member can only be set when creating a snapshot, after that it becomes read-only. snapshotLifetime String String representing a duration in ISO 8601 [17] format

0..1 Suggested duration for which the requester wants the Snapshot to exist with respect to the current point in time. The actual expiresAt time of the Snapshot shall be set by the NGSI-LD system, possibly overriding the requested duration.
